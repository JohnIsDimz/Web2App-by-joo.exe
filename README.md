## 📌 Tentang Aplikasi

**Web2App Generator Studio** adalah platform builder & converter web-ke-native generasi terbaru. Dengan platform ini, Anda dapat mengubah URL website apa pun (seperti toko online Shopee, Tokopedia, YouTube, Wikipedia, atau portal berita) menjadi aplikasi **Android APK / AAB**, **iOS App Store**, **Desktop Windows/macOS/Linux**, atau **PWA Standalone** hanya dalam hitungan detik! 🎉

## 🛠️ Teknologi Utama (Technology Stack)

<div align="center">
  <img src="https://media.giphy.com/media/v1.Y2lkPTc5MGI3NjExM3Y1b255cmZ6ejB2bXByOHltMjIyejBhcXdrOThoNXc3ZXZ3OHVsdyZlcD12MV9pbnRlcm5hbF9naWZfYnlfaWQmY3Q9Zw/kPvh7l9K4N98e9TInF/giphy.gif" width="100" alt="Cute Tech Animation" />

- **Frontend Application**: React 18 + Vite 6 + Tailwind CSS v3 + Lucide Icons + Motion (Framer Motion)
- **Backend API & Middleware**: Node.js + Express.js (`server.ts`)
- **Encrypted Relational SQL Vault**: Full SQL Database Engine dengan enkripsi militer **AES-256-GCM** & Verifikasi HMAC (`/src/lib/database.ts` & `/src/lib/sqlDatabase.ts`)
- **Real-Time Database & Auth**: Firebase Firestore & Firebase Authentication
- **Email Delivery System**: Resend Mail API dengan Template HTML Kustom untuk Pesan Selamat Datang & Reset Password

## ✨ Fitur-Fitur Unggulan

| Fitur | Deskripsi |
| :--- | :--- |
| **🛡️ Relational SQL Vault (AES-256)** | Penyimpanan data konfigurasi terenkripsi militer AES-256-GCM dengan signature HMAC. |
| **💳 Saldo Balance & Token Real-Time** | Top-up saldo, pembelian token build, dan langganan bulanan tersimpan otomatis di Firebase Firestore. |
| **📧 Notification Email Engine** | Pengiriman email otomatis sambutan hangat & link riset password aman langsung ke inbox user. |
| **💬 Native Floating Action Button (FAB)** | Tombol melayang di layar untuk WhatsApp Chat CS (`wa.me`), Telepon (`tel:`), atau JavaScript kustom. |
| **🔒 Keamanan Anti-Screenshot** | Proteksi `FLAG_SECURE` untuk mencegah perekaman layar & screenshot di Android/iOS. |
| **👆 Biometric / Fingerprint Lock** | Otentikasi Sidik Jari / Face ID sebelum halaman web terbuka. |
| **🛡️ SSL Pinning & Whitelist** | Batasi navigasi WebView hanya pada domain resmi untuk mencegah serangan Phishing / Man-In-The-Middle. |
| **🌐 Live Proxy Viewer & Simulator** | Simulasi tampilan di iPhone, Pixel, iPad, atau Desktop dengan Live Proxy bypass frame-blocking. |
| **📦 Export Kode ZIP Lengkap** | Unduh seluruh source code proyek lengkap siap *build* di Android Studio, Xcode, atau VS Code. |

## 🛠️ Perintah Utama (NPM Scripts)

| Perintah | Fungsi / Kegunaan |
| :--- | :--- |
| `npm run dev` | Menjalankan server pengembang lokal & Vite middleware di Port 3000. |
| `npm run build` | Mengompilasi proyek React & bundling backend `server.ts` menggunakan `esbuild` ke `dist/server.cjs`. |
| `npm start` | Menjalankan aplikasi versi produksi dari `dist/server.cjs`. |
| `npm run lint` | Memeriksa tipe TypeScript (`tsc --noEmit`) untuk memastikan tidak ada sintaks error. |

## 📂 Struktur Proyek

```text
├── src/
│   ├── components/       # Komponen UI utama (Configurator, DeviceSimulator, WalletModal, AuthModal, dll.)
│   ├── data/             # Preset template website (Shopee, Tokopedia, YouTube, Wikipedia, dll.)
│   ├── lib/              # Database Encrypted SQL (database.ts, sqlDatabase.ts), Firebase, & Email Service
│   ├── utils/            # Generator kode Flutter, Android Compose, Swift, & ZIP exporter
│   ├── types.ts          # Definisi TypeScript interface & tipe data (11 Native Engine Types)
│   ├── App.tsx           # Entrypoint UI React utama
│   └── main.tsx          # Render React DOM
├── server.ts             # Express.js backend, Encrypted SQL Vault Query API, & Resend Email Sender
├── package.json          # Dependencies & npm scripts
└── README.md             # Dokumentasi panduan lengkap
```
